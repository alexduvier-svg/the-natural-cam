# Referências locais do usuário

`index.json` registra as sete referências, seus hashes e critérios de observação. Os arquivos originais de imagem ficam apenas no PC e no APK local autorizado; não são versionados nem enviados ao GitHub.

Para reproduzir a biblioteca visual em outro checkout, colocar os originais correspondentes nesta pasta e conferir o SHA-256 de cada entrada. A ausência das imagens não impede a câmera de funcionar; a biblioteca informa que a referência está indisponível.

Esses exemplos não são dados de treinamento nem calibração de cor do Reno.
